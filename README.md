# Roshfrans Catálogo App

Aplicación móvil desarrollada con **React Native**, **Expo** y **TypeScript** para consultar el catálogo de productos Roshfrans de forma rápida e intuitiva.

## Características

- Búsqueda rápida de productos
- Gestión de favoritos
- Historial de búsquedas
- Soporte para modo oscuro
- Disponible para Android e iOS
- Alto rendimiento con listas virtualizadas

## Tecnologías

- React Native
- Expo SDK 54
- TypeScript
- Expo Router
- Zustand
- React Native Paper
- AsyncStorage
- FlashList

## Instalación

```bash
npm install
npm start
```

### Ejecutar en Android

```bash
npm run android
```
